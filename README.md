# Michael Rocha – E-Portfolio

This repository holds the source files for my e-portfolio, live at https://michaelrocha728.github.io. I built it for my OM 620 Tools and Technology for Analytics course at Cal State San Marcos to show my education, experience, skills, and projects.

## Pages

- **Home** (index.md): About me, education, experience, skills, projects, and contact
- **How I Built My E-Portfolio** (`building-my-eportfolio/`): A step-by-step guide to how I built this site
- **OM 620 Assignments** (`om620-assignments/`): Overview and findings from my data cleaning and safety stock assignments

## Built With

GitHub Pages, Jekyll, and the Minimal theme
